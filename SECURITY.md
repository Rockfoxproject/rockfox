# Security policy

## Reporting a vulnerability

Report problems privately, with the **Report a vulnerability** button on the [Security tab](https://github.com/Rockfoxproject/rockfox/security/advisories/new). Please do not open a public issue or pull request for a security problem.

Rockfox is a small volunteer project, so replies are best effort. Please leave a reasonable time to fix a problem before you publish it.

## What belongs here

- Rockfox's own changes: the patches, the preferences, the build and signing workflows and the update channel.
- Problems in Firefox, Zen or LibreWolf themselves belong with those projects. If you report one upstream, a note here helps Rockfox pick up the fix.

## Supported versions

Only the latest release gets fixes.

## The update signing key

Updates are signed with a key that only the maintainer holds. If you think it has leaked, report it the same way.
